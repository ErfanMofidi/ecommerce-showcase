# 🛍️ E-Commerce Showcase

A modern, responsive e-commerce website built to demonstrate my front-end development skills. This project focuses on creating a visually appealing shopping experience with clean UI components, responsive layouts, and an intuitive user journey.

## 🌐 Live Demo

👉 https://erfanmofidi.github.io/ecommerce-showcase/

---

## 📖 About the Project

This project is a front-end implementation of an e-commerce website designed to simulate a modern online shopping experience. It showcases responsive design, reusable components, interactive elements, and attention to user experience.

The primary goal of this project was to practice building a professional online store interface while applying modern HTML, CSS, and JavaScript techniques.

---

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern landing page
- Featured and popular products
- Product cards with pricing
- Shopping cart interface
- Product detail page
- Category browsing
- Promotional banners
- Newsletter subscription section
- Contact & footer sections
- Interactive navigation
- Smooth scrolling and animations
- Cross-browser compatibility
